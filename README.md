# Proyecto de Red Eléctrica

En este proyecto se busca realizar una predicción horaria de la demanda de electricidad en España.

Los datos se recogerán de la API de Red Eléctrica. Se tomará una base de datos desde enero de 2013 hasta abril de 2025.

La predicción se realizará usando modelos estadísticos (ARMA, ARIMA, y SARIMA), y modelos de machine learning (XGBoost y Prophet)
